本模组添加了一系列模块化、动态加载的实用配方，以及一系列可用于创建动态数据的 API（用于制作附属模组）；

本模组旨在使用一种更加灵活的方案，替代仅包含配方、标签等修改的轻度魔改数据包。

* **适用版本：** Minecraft 1.21.1 NeoForge

* **运行环境：** 客户端需装，服务端需装

## 特性

### 实用配方

* 腐肉换皮革；
* 粗矿物块烧炼。

### 动态数据生成

运行时生成数据，支持标签关键词匹配；

支持添加新数据和禁用已加载数据，且可在游戏内随时启用 / 禁用相关功能。

* 已支持数据类型：所有原版配方

> 例：根据 `c:storage_blocks/raw_*` 标签匹配所有粗矿物块，生成将它们烧炼成对应矿物块的配方

### 模块化加载

将一种或一系列功能相似的内容组成模块，每个模块可以单独配置是否启用。

### 游戏内配置界面

需要 [Cloth Config API](https://github.com/shedaniel/ClothConfig/) 模组。

### 自动重新加载

每次更改配置后，游戏将立即自动重新加载数据（与`/reload`相同）使变更生效（可在配置中禁用）。

### 兼容性

动态数据基于原版数据类，生成方式参考了原版数据生成（Data Generator），除增加了数据注入步骤外不修改游戏运行逻辑；

由于数据在游戏运行过程中生成，部分数据可通过标签关键词匹配并生成，不再需要为每种材料单独编写配方，且自动适配其他模组。

### 附属支持

附属模组可利用本模组的数据注入系统，只需仿照本模组模式编写模块、Mixin（如果需要支持其他模组中的自定义数据，如[机械动力](https://github.com/Creators-of-Create/Create)的加工配方）和模组初始化方法，即可实现运行时动态生成数据，并自动拥有本模组同款配置系统。
